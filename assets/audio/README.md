Put the background music in this folder: any .ogg, .mp3 or .wav file (the
first one alphabetically is used). The game plays it automatically, looping,
for the whole session (see `_start_music` in `scripts/game_state.gd`). If no
track is found, Godot's Output panel says so.

After adding the file, click back into the Godot editor so it imports it.

Current pick: track 1 of "5 Chiptunes (Action)" by Juhani Junkala, CC0 1.0,
https://opengameart.org/content/5-chiptunes-action
